# Mockup (riferimento, non codice del sito)

I file `.dc.html` sono le pagine disegnate nello strumento "design canvas". Contengono HTML con stili inline più tag e codice propri dello strumento (`<x-dc>`, `<sc-for>`, `<sc-if>`, `{{ }}`, `DCLogic`, `support.js`) che **non vanno portati nel sito** e che non si aprono in un browser così come sono.

Usali per leggere: struttura delle sezioni, colonne della griglia (`grid-column`), misure, testi, ordine degli elementi, valori degli schemi sfalsati. Per i comportamenti (carousel, filtri, caricamento continuo) leggi gli script in fondo a `Main.dc.html`, `Progetti.dc.html`, `Progetto.dc.html`, ma la specifica che vale è `HANDOFF.md` (§6).

| File | Pagina |
|---|---|
| Main.dc.html | Home |
| Progetti.dc.html | Elenco progetti |
| Progetto.dc.html | Singolo progetto (esempio: "Disney - Toy Story 5 - Premiere") |
| Studio.dc.html | Studio |
| Servizi.dc.html | Servizi |
| Contatti.dc.html | Contatti |

Le foto sono segnaposto ("Foto — ..."). Il bordo grigio dei segnaposto non va riprodotto sulle foto vere.
